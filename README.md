## 📖 What is ElectricSpawners?

Electric Spawners brings industrial mob farming to Slimefun. Capture monster souls, imprint them onto electric spawner cages, and regulate spawn rates with precision SCU power control.

---

## ⚙️ Key Features & Systems

* ⚡ **Power-Driven Spawners**: Electrically powered cages that spawn mobs without requiring vanilla player proximity.
* 🔮 **Soul Capture Flasks**: Extract essences from hostile or peaceful mobs to configure spawner targets.
* 📈 **Tiered Speed & Efficiency**: Upgrade spawner rates with capacitor modules while maintaining server TPS stability.

## 📥 Installation

1. Download the latest release `.jar` from the [Releases](https://github.com/SlimefunNewHorizons/ElectricSpawners-drake/releases) tab or [Modrinth](https://modrinth.com/organization/drakescraft-labs).
2. Place the `.jar` into your server's `plugins/` directory alongside `Slimefun4-Drake.jar`.
3. Start or restart your server. Recipes and machines will appear automatically in the Slimefun guide (`/sf guide`).

---

## 🛠️ Building from Source

```bash
git clone https://github.com/SlimefunNewHorizons/ElectricSpawners-drake.git
cd ElectricSpawners-drake
mvn clean package -DskipTests
```

The compiled artifact will be located under `target/ElectricSpawners-drake.jar`.
